# SmartEdu Cloud — Communication AI Integration & Safety Safeguards

## 1. Gemini AI Communication Services
- **Announcement Drafting (`POST /api/v1/announcements/ai-draft`)**: Generates professional title and body draft from bullet points.
- **Announcement Summarization (`POST /api/v1/announcements/ai-summarize`)**: Converts long text into brief summary and key takeaways.
- **Tone Improvement (`POST /api/v1/announcements/ai-tone`)**: Polishes draft to meet university academic standards.

## 2. Privacy & PII Sanitization
Before invoking the Gemini API, input text is sanitized by:
- Redacting JWT tokens (`eyJ...`)
- Redacting passwords and API credentials (`password: [REDACTED]`)
- Stripping personal email addresses where not relevant to context

## 3. Human Review Invariant
Every AI-generated output returns with `is_ai_generated: true` and an authoritative disclaimer: `"This draft is generated by AI. Review and edit before official publication."` The system strictly prevents automatic publishing from the AI endpoint.
